# 部署指南

## 一、局域网（课堂现场推荐）

```bash
cd templates
node server.mjs
```

- 讲师机与学员在同一 Wi-Fi；
- 学员访问 `http://<讲师机IP>:8899/live`；
- 数据落本地 `data/state.json`，课堂结束可备份或删除；
- 不需要外网。

## 二、静态托管（OSS / 任意静态站）

把 `templates` 下的 HTML 传到静态存储：

```
course/course.html
course/admin.html
course/grader.html
live.html
promo.html
materials/...
```

- 页面里的相对链接天然可用；
- 上传时设置 `Content-Type: text/html; charset=utf-8` 与 `Content-Disposition: inline`，避免浏览器下载；
- 若使用自定义域名，注意不要用根路径（如 `/promo`），一律用完整文件路径。

## 三、阿里云 FC（无讲师机时）

1. 新建服务与函数（Python 3.10，HTTP 触发器，匿名）；
2. 上传 `templates/fc/index.py`；
3. 配置环境变量：

| 变量 | 说明 |
|---|---|
| OSS_AK / OSS_SK | 有该 OSS 桶读写权限的 AK/SK（建议 RAM 子账号） |
| OSS_ENDPOINT | 如 `oss-cn-hangzhou.aliyuncs.com` |
| OSS_BUCKET | 桶名 |

4. 把三个页面里的 `FC_API` 改成函数公网地址；
5. 状态与上传文件写在 OSS 的 `course-kit/data/` 下。

**安全提示**：AK/SK 只放函数环境变量，不写进仓库；函数为匿名触发，课堂结束可停用。

## 四、更新与回滚

- 页面是单文件，直接替换即可；
- 云函数改完代码后重新发布；
- 课堂前建议清空数据：后台「清空全部学员」「清空分组」或 `/api/admin/reset`。

## 五、检查清单

- [ ] 讲师机 IP 固定、防火墙放行 8899；
- [ ] 学员扫码能打开、能抽签；
- [ ] 课件能全屏、翻页正常；
- [ ] 作业开关、工作坊开关、抢答各试一遍；
- [ ] 备份上一场数据。
