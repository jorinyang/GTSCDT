# materials（示例素材）

课堂里学员点「下载素材」拿到的文件就放这里；文件名要和 live.html 里 WS[].files 对应。

本目录只放**脱敏示例**，真实客户的报名表、结算单不要进仓库。

替换时保留文件名约定：

- T1：t1-brief.md
- T2：t2-sample.csv、t2-rules.md
- T3：t3-pack.md
- T4：t4-brief.md、t4-reference.md
- T5：t5-brief.md、t5-info.md
- T6：t6-rules.md、t6-settlement-a.csv、t6-settlement-b.csv
