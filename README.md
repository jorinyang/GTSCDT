# 弈策智询 v0.1 · GTSICCDT

**Game Theory Strategy Intelligence Consulting Course Development Tools**

把一次企业 AI 培训从「课程大纲 → 宣传页 → 课件 → 课堂后台 → 学员页 → 作业评分」整套流程，封装成一套可以反复使用的课程开发工具。

> 本仓库是**脱敏模板**：所有客户名、讲师信息、接口地址、存储桶、样例数据均为占位，替换后即可用于新客户。

## 这套工具解决什么

企业培训最容易散在三处：大纲在文档里、课件在 PPT 里、互动和作业在微信里。结果是每次开课都要重做一遍，作业收不齐、评分靠印象、复盘没数据。

弈策智询把一次培训当成一个**可运行的系统**来做：

- **课程大纲**：结构化模板，时间、模块、题目、评分、物料一次对齐；
- **宣传页**：单页 HTML，倒计时、模块、关卡、奖励；
- **课件**：14 个视图的单文件 HTML，可点击、可下钻、全屏投影；
- **课堂后台**：一个页面三个标签 —— 课堂管理（投票 / 抽签分组 / 抢答 / 表现分 / 学员）、作业评分、在线答题；
- **学员页**：手机端抽签、投票、抢答、六类作业上传；
- **作业中心**：按组分关提交、自动评分 + 人工复核、导出成绩；
- **服务端**：零依赖 Node 局域网服务，或阿里云 FC 云函数（状态存 OSS）。

## 快速开始（本地）

```bash
cd templates
node server.mjs
# 浏览器打开：
# 课件      http://127.0.0.1:8899/course
# 宣传页    http://127.0.0.1:8899/promo
# 课堂后台  http://127.0.0.1:8899/admin
# 作业中心  http://127.0.0.1:8899/grader
# 学员页    http://127.0.0.1:8899/live
```

不需要安装任何依赖。数据落在 `templates/data/state.json`（已在 .gitignore 中忽略）。

## 定制一节课，改这几处

| 要改什么 | 改哪里 |
|---|---|
| 客户名 / 品牌 / 日期 / 地点 | 各 HTML 顶部文案、课件封面 |
| 模块与小节 | `course.html` 里的 `NAV` 数组与各 `<section class="view">` |
| 六道题（题面与行动卡） | `course.html` 的 3.2 题面卡、`live.html` 的 `WS` 数组 |
| 评分规则 | `grader.html` 的 `TASKS` 数组 |
| 题库与出题 | 课堂后台「在线答题」卡片（下载模板 → 填 Excel → 导入 → 设置数量/分值 → 发布） |
| 素材下载 | `templates/materials/`（文件名与 `live.html` 的 `files` 对应） |
| 云函数地址 | 三个页面里的 `FC_API` 常量（`YOUR-FC-DOMAIN`） |
| 讲师介绍 | 课件「讲师介绍」页 + `assets/teacher-placeholder.svg` |

## 课堂机制（内置）

- **抽签分组**：A–Z 动态分组，人数平均分配、每组不超过设定上限（1–10 人）；
- **课堂表现分**：按小组加减分；
- **投票**：讲师发起，学员手机投，大屏汇总；
- **抢答**：开启 → 开始（多轮）→ 最快者胜出，其余变灰；
- **在线答题**：Excel 四 sheet 导入题库（选择/判断/填空/简答），随机或顺序抽题、按类设分，学员手机作答；客观题自动判分；简答题配置 `DEEPSEEK_API_KEY` 后由 deepseek-flash 判分（未配置则回落到相似度评分）；
- **作业提交**：讲师开关控制，学员确认后上传；支持 md / xlsx / pptx / zip / 截图；
- **工作坊**：倒计时开始即向学员页推送「行动卡 + 素材下载」；
- **评分**：产物 70% + 三问拆解 30%，自动检查 + 人工复核。

## 部署

- **局域网（推荐现场）**：讲师机跑 `node server.mjs`，学员连同一 Wi-Fi 访问 `http://<讲师机IP>:8899/live`；
- **公网静态**：把 HTML 传到 OSS / 任意静态托管，把 `FC_API` 指向云函数；
- **云函数**：`templates/fc/index.py` 可直接部署到阿里云 FC，状态与文件写 OSS；环境变量见 `docs/04-部署指南.md`。
