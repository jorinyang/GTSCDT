# 课堂使用说明（按课程流程）

> 照着这条时间线走，到哪个环节用哪个能力、怎么点、应该看到什么效果。以一天课为例：09:00–11:40 上午，14:30–17:40 下午。

## 两种讲课方式

- **A. 用本仓库课件**：`/course` 全屏播放，计时、工作坊行动卡由课件第四模块触发；
- **B. 用 PPT / 外部材料**：PPT 全屏，本工具只做课堂运营——操作台 + 大屏 + 遥控器 + 学员页。

下面每个环节都标了两种方式怎么用。

---

## 0. 课前 30 分钟（准备）

| 做什么 | 用哪个能力 | 怎么操作 | 效果 |
|---|---|---|---|
| 建今天的房间 | `/rooms` | 填课程名 → 创建 | 得到 4 位房间码，四个入口自动带码 |
| 打开大屏 | `/screen?room=CODE` | 投影/副屏打开 → 全屏 | 投影显示房间码、投票区、抢答区、积分榜 |
| 讲师登录 | `/login` | 钉钉扫码或本地口令 | 后台受保护（开了 `REQUIRE_AUTH` 时必需） |
| 绑定讲师（首次） | `/teachers` | 添加姓名、角色、钉钉 unionId | 钉钉登录能匹配到人 |
| 上传课件 | `/packages` | 选 HTML → 上传 → 预览 | 课程包进入列表，`/shell?pkg=ID` 可播 |
| 导入题库 | 操作台「在线答题」 | 下载模板 → 填四个 sheet → 导入 | 题库显示各类题数量 |
| 设好出题 | 操作台「在线答题」 | 选随机/顺序、各类数量与分值 | 点「发布」即可开考 |
| 测模型 | 操作台「模型管理」 | 填 Key/Base/Model → 测试连通性 → 保存 | 显示「连通正常 · 延迟」 |
| 关作业提交 | 操作台「作业评分」 | 开关设为关闭 | 学员页暂时不出现上传卡 |

**检查**：让一位学员先扫码进房间，确认能抽签、能投票，再开始。

---

## 1. 开场 09:00–09:20（建立秩序）

1. **学员加入**：学员扫大屏上的房间码 → `/join?room=CODE` → 填姓名 + 手机后四位；
   - 效果：操作台「学员管理」实时出现名字，大屏人数增加。
2. **抽签分组**：学员点「抽签」；讲师在操作台看分组；
   - 效果：每组人数平均、不超上限；大屏积分榜出现 A–G 组。
3. **讲积分规则**：说明「小组积分 = 表现分 + 作业分」，前三名有奖励；
4. **备好遥控器**：讲师手机打开 `/remote?room=CODE`，后面不用回电脑。

---

## 2. 上午讲授 09:20–11:40（讲授 + 互动）

### 2.1 模块一：认知（约 55 分钟）

- **投票摸认知**（操作台「投票」或遥控器）：
  - 问题例：「你觉得自己现在在哪一层？」选项：几乎没用过 / 用过聊天助手 / 每天在用；
  - 学员手机投，大屏实时涨条；
  - 效果：讲师知道该讲多深，学员看到同伴分布。
- **抢答拉注意力**（操作台/遥控器）：
  - 点「开启抢答」→「开始抢答」；学员页按钮变红；
  - 第一个点的学员胜出，大屏显示名字；
  - 再点「开始抢答」进入下一轮。

### 2.2 模块二：框架（约 75 分钟）

- 讲授为主；每 20–25 分钟插一次互动：
  - 投票：「你觉得自己最像导演、制片还是电影公司？」
  - 抢答：讲完三层能力后，问一个刚讲过的点；
- **在线答题**（可选，5 分钟）：
  - 操作台「在线答题」→ 发布（如 5 道选择 + 1 道简答）；
  - 学员手机答；大屏看已答人数；
  - 效果：客观题自动判分，简答由模型给分，讲师不用现场批。

### 2.3 茶歇 10:15–10:25

- 结束当前投票/答题；大屏可切到积分榜；
- 讲师看操作台「学员管理」，确认没人掉线。

---

## 3. 午休 11:40–14:30

- 关闭投票与答题（避免学员继续提交）；
- 如上午有作业，点「作业评分」导出一次 CSV 备份；
- 手机遥控器关掉页面即可，房间状态保留。

---

## 4. 下午开场 14:30–14:35（收心）

- **快答**：操作台「在线答题」发布 3–5 道上午知识点的题（2 分钟）；
- 大屏显示答题进度与均分；
- 效果：把注意力拉回课堂，同时检验上午吸收。

---

## 5. 工作坊 15:35–17:05（核心产出）

### 5.1 开始工作坊

- **方式 A（用课件）**：课件第四模块点「开始」→ 计时开始 → 学员页出现行动卡与素材；
- **方式 B（用 PPT）**：操作台「工作坊」→ 设 90 分钟 →「开始计时」→「推送行动卡」；
- 效果：所有学员页同时出现六关任务卡 + 素材下载；大屏显示倒计时。

### 5.2 过程中

- 大屏保持倒计时 + 积分榜；
- 讲师用遥控器：暂停/继续计时、发起临时投票（如「哪一关最难？」）；
- 学员按 T1–T6 做题，随时下载素材；
- 操作台「作业评分」看提交矩阵，哪组交了哪关一目了然。

### 5.3 提交

- 操作台「作业评分」→ 打开作业提交开关；
- 学员页出现六类上传卡（方案 md、表格 xlsx、PPT、ZIP、截图、对账报告）；
- 学员点「确认提交」才真正上传；
- 效果：提交后操作台矩阵对应格子变亮，提交列表出现记录。

---

## 6. 评分与复盘 17:05–17:40

1. **结束计时**：操作台「工作坊」暂停/重置；
2. **AI 初评**（可选）：
   - 操作台「作业评分」→ 点开某学员 → 每个任务旁「AI 评分」；
   - 模型按评分标准逐项打分并写依据；
   - 讲师复核、必要时人工改分；
3. **公布积分**：大屏积分榜；小组积分 = 表现分 + 作业分；
4. **发奖**：前三名；
5. **课堂报告**：打开 `/report?room=CODE` → 看学员、投票、答题、作业汇总 → 下载 CSV；
6. **结束投票/答题**：操作台关闭，避免课后继续提交。

---

## 7. 课后（10 分钟）

- 报告 CSV 存档，作为下一场改进依据；
- 房间数据保留（`templates/data/rooms/CODE/`）；下一场新建房间即可，不用删旧房间；
- 讲师管理里整理讲师名单与角色；
- 课程包保留在 `/packages`，下次可直接复用或复制修改。

---

## 8. 常见情况处理

| 情况 | 怎么办 |
|---|---|
| 学员打不开链接 | 确认同一 Wi-Fi；用讲师机 IP 而不是 127.0.0.1；房间码是否输错 |
| 大屏不更新 | SSE 被网络拦截时会自动轮询，等 2–3 秒；刷新一次 |
| 学员重复提交 | 系统按「姓名+尾号」识别，同一人同一关只保留一条 |
| 投票选项写错 | 结束当前投票，重新发起 |
| 抢答没人按 | 确认「开启抢答」→「开始抢答」两步都点了；学员页按钮应为红色 |
| 模型评分失败 | 操作台「模型管理」测一次连通性；没有 Key 时简答按相似度兜底 |
| 作业上传失败 | 单文件 ≤10MB；确认作业提交开关已打开 |
